# Odoo Apps: Server Tools

Odoo modules extending the `server` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Server-Tools.git ./addons/server_tools
```

## Available modules

| Module | Summary |
| --- | --- |
| [auth_disable_password_login](auth_disable_password_login) |         Disable password login for selected user. |
| [auth_impersonate_user](auth_impersonate_user) |         Impersonate another users. |
| [mail_force_from](mail_force_from) |         Setup and enforce multiple from addresses. |
| [mail_server_filter](mail_server_filter) |         Filter outgoing and incoming mail server by database name. |
| [mail_server_filter_model](mail_server_filter_model) |         Restrict mail server to messages connected to allowed data model. |
| [mail_service_users](mail_service_users) |         Exclude service users from warranty contract. |
| [prometheus_exporter](prometheus_exporter) |         Monitor Odoo metrics with Prometheus. |
| [test_bus](test_bus) |         Testing bus service |
| [web_font_calibri](web_font_calibri) |         Add Calibri to font selection. |
