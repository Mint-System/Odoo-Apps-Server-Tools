Deny login:

- Activate Module "auth_disable_password_login"
- Go to Settings > User and Companies > Users and edit arbitrary User (e.g. Marc Demo).
- In Security Tab enable "Disable Password Login".
- Open private browser window and try to login (demo/demo for Marc Demo).
- Check if access denied.

Remove password change button in user preferences:

- Enable "Disable Password Login" for logged in user.
- User cannot change password in his preferences.
